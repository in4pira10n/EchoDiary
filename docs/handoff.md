# iOS 快捷指令接力

「接力」Tab 是当前资源库的系统文件夹，使用和主页一致的笔记列表。可在其中新建日记，或通过「移到文件夹 → 接力」移入已有日记。

在「设置 → 接力」中创建和撤销密钥、查看配置。新密钥授权的是该资源库接力文件夹中的全部笔记，包含以后移入的笔记；移出后立即停止授权。接力文件夹不能重命名或删除，文件夹归属保存在原有 folders.json 中，不移动 entry 的磁盘路径。密钥只在创建时显示一次；服务器仅保存 SHA-256 摘要。撤销后，快捷指令需要换用新密钥。服务重启、切换当前资源库不会改变密钥原先绑定的资源库。

手机使用服务器的局域网地址或 HTTPS 域名，不能使用电脑上的 `127.0.0.1`。密钥放在请求头中，避免放入 URL。

## 快捷指令步骤

1. 「获取剪贴板」，保存为「剪贴板」变量。
2. 「获取 URL 内容」：`GET https://你的服务器/api/handoff/notes`。请求头添加 `Authorization`，值为 `Bearer ed_你的密钥`。保存返回词典为「日记列表」。
3. 从「日记列表」获取 `choices` 的值，使用「从列表中选取」。
4. 从「日记列表」获取 `noteIds` 词典，以选中的字符串为键取得日记 ID。标题相同的日记也能正确区分。
5. 「生成 UUID」，保存为本次请求 ID。每次运行生成一个新的 UUID；重试同一次发送时使用原 UUID。
6. 「获取 URL 内容」：`POST https://你的服务器/api/handoff/append`，添加同一 Authorization 请求头。请求正文选「JSON」，添加下面四个文本字段，使用相应变量：

```json
{
  "noteId": "所选日记 ID 变量",
  "text": "剪贴板变量",
  "format": "text",
  "requestId": "本次 UUID 变量"
}
```

`format` 可选 `text`（默认，保留剪贴板原文）或 `markdown`（解析格式）。不要手工拼接 JSON 字符串，使用快捷指令的 JSON 正文字段可正确处理引号、换行及 Emoji。

旧的单篇绑定密钥继续保留单篇限制，但目标日记也必须位于「接力」中；旧的全库密钥现在仅允许访问「接力」中的日记。升级不会自动把原有日记移入接力。

## 接口

所有响应为 JSON，禁用缓存。仅下面两个接口接受接力密钥；常规 API、资源库设置和密钥管理仍需要登录。

### `GET /api/handoff/notes`

仅列出密钥允许追加且未进入回收站的日记，包含 ID、标题、创建和修改时间；不提供正文、图片或本机路径。

```json
{
  "ok": true,
  "libraryName": "我的日记",
  "notes": [{"id":"abc", "title":"随手记", "createdAt":"...", "updatedAt":"..."}],
  "choices": ["随手记 · abc"],
  "noteIds": {"随手记 · abc":"abc"}
}
```

### `POST /api/handoff/append`

请求大小最多 1 MB。文本追加为新段落，保留标题、原有格式、附件、收藏及创建时间，更新修改时间。不创建日记，不修改图片，不恢复回收站中的内容。

```json
{"ok":true,"noteId":"abc","title":"随手记","updatedAt":"...","duplicate":false}
```

`requestId` 可选，最多 128 字节。同一密钥和 requestId 的相同请求只写入一次，后续返回 `duplicate: true`；改变日记、文本或格式返回 409。去重记录随资源库持久化，服务重启和重建索引后仍有效。并发追加按顺序提交。

失败响应为 `{"ok":false,"error":"原因"}`。常见状态：400 输入无效，401 密钥无效或已撤销，403 日记不在接力中或超出旧密钥单篇权限，404 日记不存在或已删除，405 方法不支持，409 请求 ID 冲突，503 绑定的资源库不可用。快捷指令只在 `ok` 为 true 时提示发送成功。

### 登录后的密钥管理

- `GET /api/handoff/keys`：当前资源库的密钥摘要列表，不返回密钥原文及其摘要值。
- `POST /api/handoff/keys`：`{"name":"iPhone"}`，返回 `id` 和一次性显示的 `token`。
- `DELETE /api/handoff/keys?id=密钥ID`：撤销当前资源库的指定密钥。

接力密钥不会替代网页登录，也不能删除或覆盖日记。它仍是凭证，请只保存于自己使用的快捷指令中。
